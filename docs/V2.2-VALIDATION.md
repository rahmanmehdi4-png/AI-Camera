# Camera & Pose Planner — V2.2 development QA

Status: development candidate, not a fully validated public release. This branch is separate from the stable V2.1 site.

## Implemented

- Reduced persistent tablet sidebars; tablet/phone controls use compact, collapsible task panels
- On-screen Help Mode, contextual camera help, clearer editing target and a distraction-free toolbar toggle
- Camera-relative Aim / Move / Lens controls, zoom buttons, shot pinch zoom and draggable Scene/Shot divider
- Selectable and draggable 3D camera waypoints, with ordinary left/right/up/down/toward/away controls
- Direct model surface limb selection, larger touch targets, visible selected-limb highlight, limb sliders and focus
- Real-geometry modal preview of individual solo, two-person and three-person presets before applying
- Fit Everyone workspace framing while preserving the actual shot camera
- Detailed-only LLM translation brief and start/mid/end video-shot screenshot exports with technical data
- Local IndexedDB checkpoints that can be restored without overwriting one another
- Existing formations and saved project format retained

## Verified

- TypeScript, Node regression suite and Vite build through GitHub Actions
- Static release manifest and offline asset verification
- Chromium browser UI smoke checks at 1280x800 and 390x844; Help Mode, menus, pose dialog, camera panel, timeline were checked
- A browser check found a full-height resize handle obstructing the top menu; fixed to a short central handle
- A browser check found tapping Camera did not activate camera controls; fixed
- A browser check found the phone header clipped the project name; fixed
