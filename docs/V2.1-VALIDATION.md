# V2.1 corrections and validation

## Implemented

- Existing V2 retained: all 112 standard formations, camera controls/timeline, props, prompts, project storage and exports.
- Sculpted torso, pelvis, shoulder and tapered limb surfaces, shaped jaw/nose/ears, directional face, fingers/thumbs and feet. Shared immutable geometry, 20 body meshes per person and under 12,000 body triangles. Original 19-joint rig preserved.
- Surface-based floor and reclining furniture contact. Existing saved poses remain compatible; no automatic rewriting of saved projects.
- Removed the stale startup.sh camera-v2 directory assumption. Fixed project/custom-pose creation when randomUUID is unavailable in a local HTTP preview.
- Node 22 production checks, offline cache upgrade logic, precise release identity, Cloudflare Workers static configuration and compiled ZIP workflow.
- WebGL initialization errors are visible rather than leaving a silently blank stage.

The upstream pose-library commit 6097c02 was preserved during integration. No new sexual-act presets were authored or visually validated as part of this renderer/deployment correction.

## Checks performed

- Full npm run build using Node 22.23.4: TypeScript, all 32 automated tests, Vite build, static-output verification and service-worker lifecycle checks.
- Numerical comparison of actual Three.js mannequin pivots against planner forward kinematics for all eight standard poses with nonuniform root scaling and yaw.
- Rendered vertex floor-contact checks; unrestricted articulated poses and repeated bulk changes; all 112 formations tested for independent editing, serialization and prompt generation.
- Geometry inspected through software projections of standing, sitting, kneeling and reclining meshes. This is not a WebGL screenshot or evidence of GPU performance.
- Production UI browser checks: paired seated preset, independent elbow edit (-73 and -46 degrees), persistence through reload, downloaded project JSON and prompt text inspected.
- 390 by 844 embedded browser viewport: no horizontal overflow (390px client width and scroll width); pose panel usable. Desktop layout inspected.
- Service-worker simulated lifecycle: complete precache, offline navigation and fonts/assets, network-first navigation, old application-cache deletion while retaining unrelated caches.
- Fresh recursive clone and submodule update succeeded. Existing backup preserved.
- Cloudflare Wrangler Workers configuration accepted by a dry run.
